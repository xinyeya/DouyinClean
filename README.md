## 使用

1. 安装 `DouyinClean-0.3.2.apk`。已通过 ADB 覆盖安装到本次连接的手机，保留旧版设置。
2. LSPosed 中启用“净音”，作用域只勾选“抖音极速版”。已经启用过的请确认作用域仍在。
3. 在净音设置中打开总开关，再打开所需功能。新增加的“保存视频”“保存图片”默认关闭。
4. 更新模块后彻底退出并重开抖音一次，不需要清除数据。之后直接打开抖音即可使用，不需要每次先打开净音。

设置变化会通知抖音刷新配置；打开新的菜单时应用对应开关。关闭已经隐藏的入口后，重开抖音恢复界面。净音设置页无需常驻前台；Hook 随抖音主进程运行。若抖音进程被系统结束，正在进行的保存也可能中断。

## 保存入口

| 开关 | 入口与行为 |
| --- | --- |
| 收藏表情保存 | 长按原收藏表情，预览底部并列显示原“移除表情”和绿色“下载”。保留原移除操作，不需要再次长按预览图 |
| 聊天表情保存 | 在已适配的聊天表情详情页原“添加表情”按钮旁加入绿色“下载表情” |
| 评论表情保存 | 在原“添加表情”旁加入同字号、同背景形状的绿色“下载表情”，和原按钮处于同一行 |
| 保存视频 | 适配 IM SharePanelDialog（包含功能列表异步刷新）及原有两套分享面板，增加保存行，“保存视频”直接导出当前分享作品提供的下载地址 |
| 保存图片 | 分享面板的保存行提供“保存图片”，按原顺序保存当前图文作品的全部图片；部分失败时提示成功数量 |

点击保存后直接在抖音进程中下载，不跳转净音，不弹确认页。开始、成功和失败均使用短 Toast 轻提示。保存位置仍为 `Download/净音表情`。成功轻提示显示从 MediaStore 查询的实际完整文件夹路径，例如 **`/storage/emulated/0/Download/净音表情`**，设置页保留最近的实际保存路径。

表情支持 GIF、WebP、PNG、JPEG、AVIF、HEIC、HEIF 动图与宿主支持的 VVIC 文件。先读取模型提供的本地文件或 content/file URI；失效时尝试备用地址。图片使用抖音已初始化的 Fresco 编码图片管线获取缓存或下载字节，失败时尝试 HTTPS 下载。不会把预览截图当成原表情。HEIF 动图沿用原格式和原字节，不转成静态图；外部图片查看器能否播放相应格式仍取决于查看器支持。视频支持可用的 MP4、WebM 下载文件。单张图片上限 20 MB，单个视频上限 512 MB，每次图文最多 100 张；重复点击会提示当前任务尚未完成。

不同类型的内容不一定有对应下载地址：例如纯视频没有图文图片列表、纯图文没有原视频下载地址，可能提示没有可用地址。付费、加密、链接失效或需要账号 Cookie 的资源暂不支持；不承诺去水印。服务端切换到 Lynx 表情详情或未匹配的分享布局时，不强行注入悬浮按钮；运行报告会记录未匹配的分享面板。

## 其他开关

- 常用小程序：隐藏已适配的抽屉小程序组件，不删除使用记录。
- 推荐广告、推荐直播、热点卡片：根据信息流明确类型标记过滤，保留原分页标记，不涵盖所有广告形态和热点视频。
- 直播、热点、商城/团购顶栏：在默认/服务端顶栏数据源以及推荐容器子频道列表过滤频道模型与展示 ID，标签和横向分页同时移除；推荐和关注保留。启动页如果指向已移除的已知频道则回退推荐。必须重开抖音以重新建立分页；不拦截其他入口的页面访问或全局网络请求。
- 抽屉直播广场、相关搜索：仍使用本地入口隐藏。
- 防撤回实验：仅尝试改变仍有本地内容的他人消息的 `isRecalled()` 判断。未接收、已删除或由其他逻辑控制的内容无法恢复；请单独测试消息显示与操作兼容性。

## 配置与恢复

配置 Provider 仅接受模块自身 UID 与抖音极速版 UID 的读取；只共享开关和有限的装载状态。抖音本地缓存开关，启动自动读取最新配置；读取临时失败时保留上次配置，下次返回抖音继续重试。

模块仅声明 INTERNET 权限，无统计 SDK、自动后台采集、上传、聊天内容日志或 Cookie 导出。只针对点击选中的图片使用宿主正常的图片加载管线，不复制账号 Cookie 到模块。图片地址校验受支持 CDN，http 形式只升级为 HTTPS，不使用明文回退。原生图片管线使用抖音自己的加载实现；自建 HTTPS 下载逐跳校验重定向。失败时清理暂存文件和未完成的 MediaStore 项。模块不包含检测绕过或不可检测保证。

如出现冲突，在 LSPosed 禁用模块，再结束运行并重开抖音。设置页也可以“关闭所有功能”。无需清除抖音数据；已经保存的文件不会自动删除。

## 保存失败码

| 代码 | 含义 |
| --- | --- |
| D01 | 没有可读取的本地文件或可用地址 |
| D02 | 图片管线及备用网络获取未成功 |
| D03 | 返回文件格式未识别 |
| D04 | 文件超过大小上限 |
| D05 | MediaStore 创建输出失败 |
| D06 | 输出文件写入失败 |
| D07 | 完成保存时更新失败 |
| D08 | 无法创建临时缓存文件 |
| H403 / H404 等 | 备用 HTTPS 获取返回对应 HTTP 状态 |
| D00 | 其他错误 |

轻提示和净音“最近保存结果”会显示代码与成功数量，不记录完整 URL、聊天内容和原始异常消息。仍遇到 D03 时，设置页显示最多 16 字节的文件头十六进制，便于确认遗漏的真实文件类型。失败时提供代码即可继续定位。成功不等同所有表情来源都兼容。

## 手机实测顺序

1. 收藏列表长按一张静态表情：检查原移除与下载并排，点击下载仅出现轻提示；再测试一张 GIF 或动态 WebP。
2. 评论区打开表情详情：检查下载位于添加旁边，三个按钮均可正常操作。再测聊天表情。
3. 分别启用保存视频与保存图片，打开分享面板并检查新增行；测试一段视频和一组图文，在文件管理器核对文件与数量。
4. 启用需要移除的顶栏频道后结束抖音并重开，检查标签消失、原位置没有空位、左右滑动无法进入对应首页频道；推荐/关注和普通视频仍正常。随后直接测试保存，不先打开净音，核对开关保持生效。
5. 关闭保存开关，重新打开对应菜单，核对新增按钮消失。

净音“运行状态”只说明 Hook 装载与异常状态，不等同功能测试通过。

## 源码构建

Java 原生控件工程，官方 Xposed API JAR 为 compileOnly，不打包进 APK。需要 JDK 17+、Android SDK platform 36 / build-tools 36.0.0。

```powershell
.\build-local.ps1 -Jdk '你的 JDK 路径' -Sdk '你的 Android SDK 路径'
```

输出 `app/build/manual/DouyinClean-0.3.2.apk`。本机 Gradle 的 loopback 连接异常尚未解决，交付 APK 使用上述实际 SDK 工具链构建。也保留 Android Studio / Gradle 工程供其他环境使用。

源码包不含签名密钥、构建缓存、第三方抖音 APK、反编译代码或聊天截图。自行构建会创建新的测试签名，不能覆盖不同签名的现有 APK；正式发布应使用自己的签名密钥。
